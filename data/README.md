# Data Architecture Overview

This directory houses all raw and processed dataset files for the Electronic Medical Record (EMR) analysis project.

## Directory Structure

```
data/
├── raw/            <- Original, immutable survey responses (online and offline)
└── processed/      <- Cleaned, standardized, and merged dataset outputs
```

For specific details on raw inputs, see [data/raw/README.md](raw/README.md).  
For details on generated outputs, see [data/processed/README.md](processed/README.md).
