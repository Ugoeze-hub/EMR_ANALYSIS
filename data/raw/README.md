# Raw Datasets Directory

This directory stores the original, raw data files collected from healthcare facilities via online and offline EMR surveys.

## Datasets Expected

| File Name | Description | Source |
| :--- | :--- | :--- |
| `EMR analysis online.xlsx` | Raw survey responses captured via digital form | Online Survey Form |
| `EMR analysis offline.xlsx` | Raw survey responses collected manually/paper | Offline Facility Audits |
